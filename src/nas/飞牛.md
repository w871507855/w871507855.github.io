### 2. 创建docker compose
路径选择刚才创建的目录

### 3. 编写docker compose
- MYSQL_ROOT_PASSWORD是必填的root用户密码
- MYSQL_DATABASE，MYSQL_USER，MYSQL_PASSWORD是选填
```
version: "3.8"
services:
  mysql:
    image: mysql:8.0
    container_name: mysql8
    environment:
      MYSQL_ROOT_PASSWORD: xxx
      MYSQL_DATABASE: xxx
      MYSQL_USER: xxx
      MYSQL_PASSWORD: xxx
      TZ: Asia/Shanghai
    ports:
      - "13306:3306"
    volumes:
      - ./data:/var/lib/mysql
      - ./log:/var/log/mysql
      - ./conf.d:/etc/mysql/conf.d
      - /etc/localtime:/etc/localtime:ro
    restart: always
```

### 4. 点击确定后即可运行
- 修改docker compose中environment变量，需要先构建后再运行

## 飞牛搭建docker加速源
飞牛自身可以使用飞牛官方的docker加速源，局域网其他设备docker需要使用kspeeder来进行加速
### 1. 创建目录
![image.png](https://img.lichengcheng.top/20260108104154.png)
### 2. 创建docker compose
![image.png](https://img.lichengcheng.top/20260108104725.png)

### 3. 编写docker compose
- 5003是web页面访问端口
- 5443是docker加速源
```
services:
  kspeeder:
    image: registry.kspeeder.com/linkease/kspeeder:latest
    container_name: kspeeder
    ports:
      - "5443:5443"
      - "5003:5003"
    volumes:
      - ./kspeeder-data:/kspeeder-data
      - ./kspeeder-config:/kspeeder-config
    restart: unless-stopped
```
![image.png](https://img.lichengcheng.top/20260108104848.png)

### 4. 添加私有仓库加速源
修改/etc/docker/daemon.json
- 192.168.123.76为我飞牛的ip
- 5443是docker compose中设置的访问端口
```shell
"insecure-registries": ["192.168.123.76:5443"]
```

## 局域网docker加速源

### kspeeder

- 地址：[首页 - KSpeeder - 告别下载不畅，Docker 镜像下载速度 10 倍提升](https://kspeeder.com/#install)
    

#### docker部署

```docker-compose
services:
  kspeeder:
    image: registry.kspeeder.com/linkease/kspeeder:latest
    container_name: kspeeder
    ports:
      - "5443:5443"
      - "5003:5003"
    volumes:
      - ./data:/kspeeder-data
      - ./config:/kspeeder-config
    restart: unless-stopped
```

#### 局域网内使用docker加速源

1. 安装kspeeder
    
2. 在使用设备的hosts文件中添加本地域名映射
    
    1. windows：
        
    2. linux和mac：/etc/hosts
        

```shell
# IP_ADDRESS=部署kspeeder的设备ip
IP_ADDRESS registry.linkease.net
```

3. 添加加速源 /etc/docker/daemon.json
    
    ```shell
    {
      "registry-mirrors": ["https://registry.linkease.net:5443"]
    }
    ```
    
4. 重启docker

## strm工具

### litepan

- 地址：[Ponphil/LitePan: LitePan - 多网盘聚合挂载，支持 WebDAV、STRM、媒体整理、本地挂载、串联任务](https://github.com/Ponphil/LitePan)

#### 部署

```docker-compose
services:
  litepan:
    image: ponphil/litepan:v0.5.5-beta
    container_name: litepan
    restart: always
    network_mode: host
    environment:
      - TZ=Asia/Shanghai
    volumes:
      - /vol1/1000/litepan/data:/app/data
      - /vol1/1000/litepan/Strm:/app/strm
      - /vol1/1000/litepan/mounts:/app/mounts:shared
      # 可选：将 FUSE 读缓存单独映射到更快的磁盘
      - /vol1/1000/litepan/fuse_read_cache:/app/data/fuse_read_cache
    devices:
      - /dev/fuse:/dev/fuse
    pid: "host"
    privileged: true
    # 若本机访问 TMDB 困难，可取消注释并填写可用 IP
    extra_hosts:
      - "api.themoviedb.org:3.170.19.104"
      - "image.tmdb.org:169.150.236.99"
```
